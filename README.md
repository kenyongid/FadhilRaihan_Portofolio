# Fadhil Raihan — Personal Portfolio

Website portofolio pribadi yang menampilkan profil, pengalaman, proyek, prestasi, dan perjalanan saya di bidang teknologi informasi.

Di dalam portofolio ini terdapat beberapa bagian utama:

- **About Me** — Perkenalan diri, latar belakang pendidikan, dan minat di bidang teknologi informasi.
- **Projects** — Kumpulan proyek yang pernah dikerjakan, mulai dari pengembangan website, sistem informasi, aplikasi mobile, hingga sistem rekomendasi berbasis AI.
- **Experience & Activities** — Pengalaman magang di Crocodic, kegiatan organisasi kampus, pengalaman sebagai MC dan moderator, pemateri, serta aktivitas KKN dan pencak silat.
- **Achievements & Certifications** — Prestasi di bidang kickboxing dan pencak silat, sertifikasi kompetensi, serta dokumentasi seminar dan kegiatan akademik.
- **Contact** — Informasi kontak, tautan GitHub dan LinkedIn, serta bidang pekerjaan yang ingin saya tekuni.

Portofolio ini dibuat sebagai tempat untuk memperkenalkan kemampuan, pengalaman, dan hasil pekerjaan saya secara lebih terstruktur kepada recruiter, perusahaan, maupun pihak lain yang ingin mengenal profil profesional saya.
