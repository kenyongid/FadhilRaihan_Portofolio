CASE STUDY · AI INTEGRATION

Penahero AI Recommendation System

Problem Statement

Users seeking fragrance products often struggle to articulate their scent preferences, occasion needs, or characteristic notes. Standard static catalog filters frequently return either zero matches or overwhelming lists with no explanatory reasoning.

Proposed Solution & Architecture

Developed a conversational recommendation application using a Retrieval-Augmented Generation (RAG) architecture. Product records serve as an authoritative knowledge base. Textual descriptions are converted into vector embeddings, indexed within ChromaDB, and retrieved via cosine similarity. Retrieved context is passed to Google Gemini to formulate grounded recommendations.

User Prompt → Gemini Embeddings → ChromaDB Vector Search (Top-k context) → Prompt Formulation → Gemini LLM Response Generation → Laravel View

Technical Decisions & Engineering Considerations

  • Hallucination Mitigation: Prompts are strictly bounded by retrieved product records so the model does not invent fictitious items.
  • RAG Quality Evaluation: Evaluated using the RAGAS framework across metrics including faithfulness, answer relevancy, context precision, and context recall.
  • Admin Dashboard: Implemented Laravel backend controllers for product catalog CRUD and review of conversational logs.

Evaluation & Testing Results

Documented in academic testing: 100% functional test success across defined Black Box test cases, and a 92.25% User Acceptance Testing (UAT) score categorized as “Very Feasible”.

CASE STUDY · WEB RESERVATION SYSTEM

SportSpace: Sports Facility Reservation

Problem Statement

Sports facilities often face double-booking conflicts, manual booking proofs via messaging apps, unrecorded beverage add-on sales, and fragmented reporting for administrative staff.

Implemented Solution

Built an end-to-end reservation platform using Laravel and MySQL. The system validates field availability against date and hour ranges, prevents slot collisions, allows customers to add optional concession products, and issues a downloadable PDF booking certificate with unique reference codes.

Verified Features & Controller Architecture

  • Collision Prevention: BookingController::slotTerpakai verifies occupied intervals before accepting a reservation transaction.
  • Add-on Products: Integrated concession purchasing linked to the booking transaction (simpantambahan).
  • PDF Reporting: Generates booking proofs with DomPDF and allows admins to export transaction logs to PDF, CSV, and Excel.
  • Visual Dashboard: Reservation counts and activity trends visualised through ApexCharts.
